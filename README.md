## The line

> We're monetising the last untapped urban real estate: your statue. For just $2 a crumb, your brand gets premium head placement. Our pigeons, your pigeons, one flock.

## What this entry does

`main.ts` (Node 22) writes exactly one original line — the elevator pitch
a city pigeon gives to investors for its startup — to `/output/entry.txt`.
The program is deterministic, uses no network, and has no dependencies: it
only creates `/output` if missing and writes the line as UTF-8 text with
no trailing newline.

## How to run

```sh
node main.ts
cat /output/entry.txt
```
